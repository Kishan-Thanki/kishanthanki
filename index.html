A bit about me.

How I think about the work, in a few paragraphs.

I'm a Software Engineer working on building reliable systems, automation, and scalable deployments. My work tends to sit behind the scenes — the systems, infrastructure, and pipelines that need to keep working long after the demo is over.

I care about clean architecture over clever shortcuts, decisions backed by evidence rather than assumptions, and systems that are boring in the best way: predictable, well-documented, and easy for someone else to pick up. I'm as comfortable working close to the infrastructure layer as I am building the services that run on top of it.

  • Designing the parts users never see — backend services and internal systems built to be dependable, not just functional.
  • Making releases boring — automating the repetitive parts of shipping so deployments are predictable, not eventful.
  • Building for the failure case — designing for graceful degradation and real-world conditions, not just the ideal path.

01 LIVE

Resume Ranker

AI / BACKEND / gRPC

Resume Ranker helps hiring teams review candidates faster by comparing resumes with job descriptions and turning unstructured experience into clear, evidence-backed match insights.

  • Compares candidate resumes with job requirements across skills, experience, education, and projects to surface the strongest matches.
  • Connects match assessments to evidence from the original resume and job description, helping reviewers understand why a candidate was ranked.
  • Transforms resumes and job descriptions into structured information so hiring teams can evaluate candidates consistently.

02 OPEN SOURCE

DepCycle

PYTHON / CLI / GRAPH ANALYSIS

A Python CLI that maps project dependencies, reveals circular architecture, and turns complex codebases into clear, explorable dependency graphs.

  • Scans Python projects to show local, standard-library, third-party, and unresolved dependencies in one graph.
  • Finds circular dependencies and shows the exact cycle path, with problematic edges highlighted in generated reports.
  • Supports interactive HTML, machine-readable JSON, and DOT graph output.
Python Dependency Mapping Cycle Detection CLI

03 DEPLOYED

Placemate

DJANGO / REST / POSTGRESQL

A centralized campus recruitment system using Django REST Framework to automate placement workflows, manage production configurations, and securely isolate user data.

  • Architected a backend for a centralized campus recruitment system using Django REST Framework.
  • Implemented stateless authentication using HTTP-only cookies and JWTs with role-based and object-level permissions.
  • Developed middleware and BaseViewSets for unified JSON responses and centralized exception handling.
  • Deployed the production backend on Render and integrated Cloudinary for media storage.
